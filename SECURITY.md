# Security contact

Report a reproducible concern privately to Offentlogspot@gmail.com. Include a URL, time and
minimal description. Never send credentials or another person's private data.
No bug bounty, penetration-testing authorisation or response SLA is offered.

This repository is public. Browser code, static data and committed assets are
inspectable. The evaluation checkbox and robots.txt are not access controls.
Keep confidential code and credentials outside public source and deployment
assets. Use platform access controls for restricted evaluations.
